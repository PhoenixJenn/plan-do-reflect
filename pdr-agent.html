PDR Agent

Plan-Do-Reflect isn't just a set of pages to read — it's meant to be run. This is the agent that helps you actually run it.

Code-named Proteus, after the shape-shifting Greek sea god — the point isn't to track how you work, it's to change it. It stays focused on what matters, protects your calendar, documents and reflects daily, and puts this site's one-pagers into practice one book at a time, in your own workday rather than in the abstract.

This page is still being built out. In the meantime, the project itself lives on GitHub: github.com/PhoenixJenn/proteus.
