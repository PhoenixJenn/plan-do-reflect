The Framework

The part of the cycle nobody assigns to you — how you run yourself before you try to run anything else.

Root category 3 stages + core skills

Every other area on this site — Leading, Managing, Strategic Planning — assumes you've already got a handle on running yourself. This is that handle. It's also the only root that's genuinely cyclical: Reflection feeds Planning, Planning feeds Focus and Time Management, and when the whole system wobbles, Motivation is what keeps you doing the work anyway.

Tools

One concrete way to run the whole loop: Bullet Journaling — rapid logging in brief daily entries, migrated forward instead of left to pile up in old notebooks. Worth its own deep dive later; for now, the short version is write it down, whether digital or analog — calendar, post-its, or a list — the format matters less than the habit of writing it down at all.
