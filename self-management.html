The Framework

The part of the cycle nobody assigns to you — how you run yourself before you try to run anything else.

Root category 3 stages + core skills

Every other area on this site — Leading, Managing, Strategic Planning — assumes you've already got a handle on running yourself. This is that handle. It's also the only root that's genuinely cyclical: Reflection feeds Focus, Focus feeds Time Management, Time Management makes Habits possible, and when the whole system wobbles, Motivation is what gets you back to Reflection to start again.
